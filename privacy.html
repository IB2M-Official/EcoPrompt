EcoPrompt

Privacy Policy & Transparency Statement

🌱 100% Local Privacy
Last updated: August 2026 • Manifest V3 Compliant
Privacy Summary: EcoPrompt operates completely offline in your browser. We never collect, store, transmit, or monetize your prompt content, browsing activity, or personal data.

1. Zero Data Collection

EcoPrompt is built on the fundamental principle of zero-knowledge privacy:

  • No Prompt Content Saved: When you send a query on ChatGPT, Gemini, or Claude, EcoPrompt only reads the character count in temporary memory to estimate computation scale. The text itself is never written to disk or logged.
  • No Personal Identifiers: We do not collect your IP address, email, location, device fingerprint, or account information.
  • No Browsing History: Only supported AI interfaces (ChatGPT, Gemini, Claude) are monitored for form submissions. No other web pages are accessible.

2. Local In-Browser Processing

All algorithmic calculations for ecological impact (CO₂, water, energy) and financial estimations run strictly within your local browser runtime.

Historical statistics (daily, weekly, monthly totals) and user settings (quotas) are stored securely inside your browser's private sandbox via chrome.storage.local. This data never leaves your device.

3. No Remote Servers & No Tracking

  • No External API Calls: EcoPrompt does not communicate with external analytics backends, telemetry servers, or telemetry SDKs.
  • No Cookies or Ads: There are no third-party cookies, advertising trackers, or fingerprinting scripts embedded in the extension.
  • Open Source & Auditable: The full source code is publicly accessible on GitHub for transparency and independent security auditing.

4. Permissions Transparency

EcoPrompt requests the minimum necessary Chrome permissions to perform its measurement function:

  • storage: Used strictly to save daily aggregated counter metrics and user quota preferences locally on your machine.
  • notifications: Used to show daily/monthly environmental recap digests if enabled.
  • alarms: Used for periodic local reset and scheduled digest checks.
  • host_permissions (ChatGPT, Gemini, Claude): Required to inject the lightweight client script that detects prompt submission events on supported AI platforms.

5. Contact & Author

EcoPrompt is developed and maintained by IB2M as an independent open-source sustainability initiative.

If you have questions, feedback, or suggestions regarding this privacy policy, feel free to open an issue on GitHub or reach out via Ko-fi (IB2M).
